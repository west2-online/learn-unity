# 西二在线简介

西二在线成立于1998年，是福州大学官方认证的学生技术组织，致力于为校园提供技术服务和创新支持。作为西二在线的核心部门之一，Unity & UE 技术部专注于游戏开发、虚拟现实(VR)和增强现实(AR)技术的研究与实践。

我们相信游戏不仅是娱乐，更是一种全新的交互方式和艺术表达形式。通过技术与创意的结合，我们致力于打造富有创意和影响力的游戏作品，探索游戏在教育、文化、社交等领域的更多可能性。

# 培养介绍

熟练掌握游戏引擎的优势主要有两方面：一方面是如果以后想钻研软件工程或者图形学等专精某一系统的内容，实际上手这样一个综合性极强的大规模软件工程项目是很有帮助的，在引擎里可以编写自己着色器进行尝试，也可以尝试自己完成实现一些引擎的组件；另一方面，对于想要入行多媒体行业的同学来说，学习引擎的经历能够在简历上提供不小的优势，如今包括游戏行业，电影行业等等都需要类似于引擎一样的技术支撑。

我们的优势主要在于能让各位同学在大学本科期间就能系统地接触到游戏引擎相关的内容，同时我们能够提供一个内部组队交流的平台，同时我们和前几届的学长联系比较紧密，能够提前获取一些行情。

## 培养内容

本组现在主要是以游戏开发的方向来培养组内同学，因为开发游戏本身也是最理想最直白的能接触到各个引擎组件的方式。我们还简单地把同学分为了程序、策划、美术三个方向，主要参考了当今常见的游戏开发分工，同时使同学们能够更方便地组队参加比赛或其他开发项目来锻炼自己。

- **程序**：客户端开发、游戏逻辑实现（Unity C# / UE5 C++ 双引擎）
- **策划**：游戏玩法设计、数值设计、团队协作上的管理分配
- **美术**：游戏的美术表现、渲染、视觉效果

## 组员活动

成为了正式西二在线的组员之后，我们会主要集中参与各大游戏开发赛事，同时钻研自己方向上的内容，部分同学会与美院的同学合作以及完成少量的外包项目。对于想要进入游戏行业的同学，这样比赛开发经历基本是必不可少的内容，同时成绩较好的话可以直接获得在大厂实习的机会。
