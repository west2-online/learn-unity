# 游戏美术介绍

游戏美术负责游戏里所有「看得见」的部分：角色、场景、UI、动画、特效。美术方向分 2D、3D 与技术美术（TA）三条路线，入组后按兴趣选择深入。

- [2D 美术](./2D美术/README.md) — 平面美术：UI 设计、立绘插画、2D 序列帧/骨骼动画、像素画
- [3D 美术](./3D美术/README.md) — 立体内容：角色/场景建模、纹理贴图、绑定骨骼、3D 动画
- [技术美术（TA）](./技术美术/README.md) — 程序×美术桥梁：渲染 Shader、特效、工具链、性能优化

> 💡 美术不只是「画得好看」。素材进到引擎里能不能正常显示、缩放会不会糊、动画能不能跑，这些是美术和程序对接时最常踩的坑。我们希望你既会画，也懂引擎里那套素材规范。
>
> 想走 TA 路线需要一定编程基础（Shader / 蓝图 / Python 至少会一个），还要补线性代数，做好长期作战的准备。
