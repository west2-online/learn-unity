# 游戏策划介绍

游戏策划是游戏开发里把「想」落实到「设计」的方向：负责玩法、剧情、数值、关卡等内容的定义。入门思路一般是**拆解游戏**——把里面用到的文案、战斗、关卡设计、数值、技术提取出来，形成自己的一套方法论，也就是你能用自己的方式去理解一个游戏的设计，并给出对应的改进或创新。

> 因为策划一旦往下细化，网上成套的资料比较少，所以这里先提供一部分入门资料，方便你们往更深的方向走。
