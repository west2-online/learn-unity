# 技术美术（TA）考核流程

## 方向定位

技术美术（Technical Artist，TA）是程序和美术之间的桥梁：既要懂美术的审美和流程，又要懂程序的技术和实现，把两者翻译成彼此能听懂的话。

TA 的核心能力是「把效果落地」：美术想要一个风格化渲染 → TA 写 Shader 实现；程序需要素材规范 → TA 定标准和工具链；游戏跑不动 → TA 做性能优化。

**⚠️ 前置警告（参考 2023 年学长的话）：** TA 是国内游戏行业最卷的方向之一。它不像程序、美术那样是团队刚需，但 TA 一个人就能扛起小项目的渲染和工具链。要学的东西很多：Shader、渲染管线、图形学基础、至少一门编程语言、美术工具链……

**没学线性代数的话，学 TA 几乎不太可能。** 如果还没学，建议先自学（B 站 3Blue1Brown 线性代数的本质），或者先按 3D 美术 + 程序两条线培养，等线代基础有了再转 TA 也不迟。

如果觉得太多太累，趁早换方向；如果决定走这条路，那就做好长期作战的准备。这一轮我们会认真考察你的「卷力」和「自学力」。

## 子路径导航

TA 内部不是铁板一块。**报名时只分大方向，子路径是导航不是分班**——第一轮后自然分化，第三轮会在你选的子路径上深入：

- **渲染 TA**：Shader、风格化渲染、光照——最经典也最卷的 TA 路线
- **特效 TA**：VFX、粒子、Niagara/VFX Graph——技能特效到环境特效
- **工具 TA**：DCC 插件、引擎编辑器扩展、自动化管线——「程序里的美术服务」
- **性能 TA**：Profiling、Draw Call / 内存 / 材质变体优化——后期项目刚需

前期地基（线代 + Shader + 引擎架构）三条路都要打，子路径决定后期专精方向。

## 学习轮

时长：一个月

在这一轮中，我们希望你去打三块地基：**数学基础、渲染基础、引擎基础**。

1. **线性代数**（没学的必补）：向量、矩阵、变换、点乘叉乘。推荐《线性代数的本质》+ 学校课程
2. **Shader 入门**：
   - 入门走节点化编辑器快速建立感觉（Unity 是 Shader Graph，UE 是 Material Editor，都是连连看）——**但连连看只是起步，用一两个星期就该丢掉**
   - 手写 Shader 走 B 站「庄懂」的入门课程，然后读冯乐乐《Shader 入门精要》并跟着敲（UE 里对应的是 HLSL 写的 .usf/.ush，原理通用）
   - 小红书/B 站卖 TA 课的很多，基本没营养，别花钱。网上都能找到原版案例
3. **引擎基础**：至少熟悉一个引擎的渲染架构——Unity 渲染管线（SRP/URP/HDRP）或 UE 渲染管线（Forward/Deferred、Nanite、Lumen）、材质、光照、后处理。双引擎都懂是加分项

这一轮以理论学习和跟随练习为主，不要求完整工程产出，但我们希望看到你的学习轨迹（笔记、练习的 Shader 效果截图都算）。

关于 AI：AI 写 Shader 很强，但**你必须理解它写的每一行**。只会复制粘贴的「TA」和会连连看没什么区别。我们最后会提问的。

（最终考题已经安排人去做了）

## 第一轮

时长：两个月

在这一轮中，你要独立完成一个「效果落地」项目：把一种视觉风格/效果，从想法做成引擎里能跑的东西。

方向任选：

1. **风格化渲染**：卡通描边、水彩、像素风、三渲二……做一个场景或角色，用自定义 Shader / 材质实现目标风格
2. **特效系统**：技能特效 / 环境特效（Unity 用 VFX Graph 或 Shuriken，UE 用 Niagara，配合自定义材质/Shader）
3. **工具链**：做一个美术向的引擎编辑器工具（Unity 编辑器扩展或 UE Editor Utility Widget / Python 脚本：批量处理素材、自动命名/导入规范检查、一键生成占位资源等）——这个方向偏「程序里的美术服务」，同样算 TA 本事

交付要求：

- 一个能跑的工程 / 场景（Unity / UE 任选），效果清晰可见
- 说明文档：目标效果是什么、用了什么技术方案、遇到哪些坑、性能上做了什么考虑
- 如果是 Shader / 材质，**展示你的参数面板**——一个可调参的材质比写死的效果强得多

**注：这个方向最容易「用 AI 水过去」，我们审查会重点看你对实现的理解。答辩时请讲清楚原理。**

## 第二轮（寒假轮）

时长：一个月

在这一轮中，你会参加为期 12 天的萌芽 GameJam，第一次在团队里做完整游戏。

**TA 的 GameJam 现实：** 大概率 GameJam 里用不到你完整的 TA 能力（小项目用默认渲染就够）。但这恰恰是考察你「桥梁作用」的时候：

- 帮助美术把素材规范定下来（尺寸、命名、格式、PPU/导入设置）
- 帮助程序解决渲染层面的问题（性能、效果、平台差异）
- 如果项目做风格化渲染，那就是你大展身手的时候
- 学会「在有限时间内决定哪些效果值得做」

**附加作业（完成有加分，参考 2023 年规则）：** GameJam 之外，TA 有附加作业，这也是你的主战场：

1. **（检查）3D 建模基本功**：完成 3D 美术同款闹钟建模，交渲染图 + 布线图（务必四边面为主）。TA 拥有「修改有问题的模型」的能力很重要，边角圆润度、渲染锯齿都要处理好
2. **（不检查）Shader 精进**：跟着《Shader 入门精要》或庄懂课程继续学，学多少是多少，我们会通过后续答辩考察
3. **（不检查，没学线代的略过）Games101 前 9 节**：渲染管线部分，对 TA 非常重要。有兴趣可以做下作业分析代码框架

答辩时请告诉我们你在团队里的实际分工，GameJam 作品 + 附加作业一起算分。

## 第三轮（最终轮）

时长：整个学期

在这一轮中，你要在 TA 的方向上深入，做出一个有分量的作品。

你可以选一个方向深耕：

- **渲染方向**：完整实现一种风格化渲染管线（NPR、水、体积光……），从原理到实现讲清楚
- **特效方向**：一套成体系的游戏特效（角色技能 + 环境 + UI），含性能和风格统一
- **工具链方向**：一套美术向生产力工具（DCC 插件 / 引擎编辑器扩展 / 自动化导入管线），让团队效率起飞
- **性能优化方向**：对一个现有项目做 Profiling + 优化（Draw Call、内存、材质变体），量化前后对比

可以组队参加比赛（大学生 Unity 游戏创作比赛等），也可以独立做 TA 作品集。不要求完整游戏，但**请展示你的思考深度**：为什么选这个方案、原理是什么、对比过哪些替代方案、性能怎么权衡。

答辩时我们会对你的实现进行提问（原理 + 细节 + AI 使用边界），请做好被拷问的准备。我们希望你在 TA 这个职责上，已经有了自己的技术积累和判断力。
