# 2D美术考核流程

**定位：2D美术需要承担团队里的平面美术，包括但不限于UI设计、立绘（插画）、2D序列帧动画、2D骨骼动画等。**

如果你希望从事UI设计，你可以去西二前端组看看。

## 学习轮

时长：一个月

**注：你或许需要一些绘画基础**

在这一轮中，你需要学习工具和引擎的使用。

首先是Unity和UE引擎，你不需要去学会完整的引擎使用，但是你要明白如何导入资产，不要出现美术除了画画什么也不会的情况。

美术和程序协作时，最常见的坑不是画得不好看，而是素材进引擎后出了问题。这一轮你需要搞明白下面这条链路（以 Unity 为例，UE 的 Paper2D 概念一一对应）：

- **Filter Mode（纹理过滤）**——为什么素材拖进场景会发糊
- **PPU（Pixels Per Unit）**——为什么素材显示大小不对
- **Sprite Mode / Sprite Editor**——怎么把序列帧大图切成单帧
- **Sprite Atlas（图集）**——图集是什么、为什么要打包
- **Animation / Animator**——怎么让素材动起来

这些不用学得很深，但至少要知道它们的存在和用途，不要什么都扔给程序。

然后，不同的方向有不同的工具。

绘图：Krita、PhotoShop等

像素画：Aseprite、Piskel等

矢量图：Adobe Illustrator等

当然我们也希望你去学习现代的AI工作流，可以是本地模型的使用，也可以是完善的AI绘画，但是请注意，你要创作的一定是有诚意的作品，不要把自己变成提示词自动机。

## 第一轮

时长：两个月

在这一轮中，你需要进行一次实践。

你只需要提供给我们一个作品，类型、种类、题材等等均不限制，你只需要保证你的作品是有诚意的，并且证明你没有在偷懒即可。

## 第二轮（寒假轮）

时长：一个月

在这一轮中，你会接触第一个完整的游戏项目。

我们希望你可以去参加萌芽gamejam，这是一个面向新手的gamejam，我们希望你在这里学到团队合作经验以及面向真实项目的资产设置，你可以去和一起参加考核的人组队，也可以去比赛群里组队。

比赛结果不会影响考核。

但是我们在最后会有答辩，到时候请带上你在比赛过程中创建的资产以及设计思考。

我们不会限制你使用AI，但是请保证你不是一个提示词自动机。

## 第三轮（最终轮）

时长：四个月

在这一轮中，我们希望你在方向上进行深入。

方向：

- UI设计（如果你希望从事UI，你可以去隔壁西二前端组看看）
- 立绘/插画
- 像素画
- 2D动效（Spine/Live2D/序列帧动画）
- 2D骨骼动画
- 技术美术（shader、特效等）。你可以需要一些代码基础，C、python、Unity和UE的蓝图使用等。

你可以任选一个方向进行深入，不属于这里的也可以，但是请对自己未来的方向负责。

在这次考核中，你可以去组队参加一个比赛，在项目中加深自己的能力，也可以专心于自己的方向（在面试中作品集是很重要的）。

在这一轮结束后，我们希望你可以展示出自己的学习成果，可以是一套UI，可以是一段动画，什么都可以，我们鼓励你有自己的创意。

最重要的要求，我们希望你创造的是有诚意的作品，你要热爱自己的创造。
