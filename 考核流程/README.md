# 西二在线 Unity & UE 技术部 · 考核流程

2026 年度纳新考核流程大纲，按方向划分。整体节奏：

| 阶段 | 时间 | 内容 |
|------|------|------|
| 学习轮 | 10.5 - 11.10 | 基础学习：语法 + 引擎上手 + 理论 |
| 第一轮 | 11.11 - 12.15 | 个人 demo / 作品 |
| 第二轮（寒假轮） | 1.5 - 2.5 | 萌芽 GameJam（12 天）团队项目 |
| 第三轮（最终轮） | 2.10 - 8.30 | 方向深入 / 中大型项目 |

> ⚠️ 学习轮答得不太离谱都不会筛人——这一轮目的是摸清你的水平、测试自学能力，不是劝退。
> 允许查阅文档、允许使用 AI 辅助，但请确保你真正理解自己写下的每一行。
