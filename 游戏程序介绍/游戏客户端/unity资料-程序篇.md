## 一、C# 基础 —— 编程入门

**目标**：掌握变量、数据类型、运算符、条件分支、循环、数组、方法（函数）等最基础的编程语法，能独立写简单的控制台程序。

推荐资源（二选一即可，但更推荐从 C++ 开始打底）：

- 黑马程序员·C++ 教程（从0到1入门编程）

- 唐老狮·C# 入门（Unity 系列四部曲之一）

- 每学一个语法点，立刻在 Visual Studio 或 Rider 中敲代码验证。

## 二、C# 进阶 —— 核心语法

**目标**：掌握面向对象（类、对象、继承、多态、接口）、异常处理、委托与事件、泛型、LINQ、集合（List/Dictionary）等 C# 的高级特性。这部分是 Unity 脚本编程的基石。

推荐资源：

- 唐老狮·C# 核心（四部曲第二部）

[【唐老狮】Unity系列之C#四部曲---C#核心_哔哩哔哩](https://www.bilibili.com/video/BV1tV411q7Rq?spm_id_from=333.788.recommend_more_video.1&trackid=web_related_0.router-related-2589621-tj4lz.1787727199646.212&vd_source=d3dcaa66010eafd10260f29f660d08d9)

**学习建议**：

- 重点理解“继承和多态”在游戏角色设计中的应用（比如敌人基类 → Boss/小兵子类）。
- 委托和事件是 Unity UI 交互、自定义回调的常用工具，务必多写示例。
- 完成一个小型控制台游戏（如回合制战斗模拟），把面向对象全用上。

**目标**：熟悉 Unity 编辑器操作，掌握 MonoBehaviour 生命周期、GameObject、Transform、组件获取、物理系统（Rigidbody/Collider）、输入系统、协程、预制体、UI 基础等。能独立制作一个简单的小游戏（如 Flappy Bird 或 3D 拾取球）。

推荐资源：

- 唐老狮·Unity 入门（四部曲第三部）

## 四、设计模式 —— 代码结构的通用“配方”

**目标**：理解游戏开发中常见的设计模式（单例、工厂、观察者、状态、策略、对象池等），学会如何让代码更易维护、扩展和复用。设计模式不是“死记硬背”，而是解决特定问题的经验总结。

推荐资源（两篇均可参考）：

- [知乎专栏 · 设计模式在 Unity 中的实践](https://zhuanlan.zhihu.com/p/39707078)
- [Unity中常见的设计模式（CSDN）](https://blog.csdn.net/Asklyw/article/details/131081166)

**学习建议**：

- 不要一次性学所有模式，先掌握最常用的：单例模式（全局管理器）、观察者模式（事件系统）、对象池模式（频繁创建销毁的子弹/敌人）。
- 尝试把你之前的 Unity 小项目用设计模式重构一遍，体会变化。
- 重点理解“面向接口编程”和“解耦”思想。

---

## 五、简单框架 —— 多个设计模式的集合，搭建项目骨架

**目标**：将设计模式组合成一个可复用的底层框架，用于管理资源的加载与卸载、内存（GC）优化、场景切换、音频管理、UI 管理、事件中心等。框架的目的是让你在开发大型项目时，不用重复造轮子，专注于游戏逻辑本身。

推荐资源：

- [Unity 框架集合（持续更新）· CSDN](https://blog.csdn.net/lihuixiaodui/article/details/139635579) —— 汇总了多种开源框架，可以对比学习。
- 唐老狮·Unity 程序基础框架（针对有一定基础的学习者）

[【唐老狮】Unity的程序基础框架（针对有一定Unity基础的学习者）_哔哩哔哩](https://www.bilibili.com/video/BV1C441117wU/?spm_id_from=333.337.search-card.all.click&vd_source=d3dcaa66010eafd10260f29f660d08d9)

**学习建议**：

- 先理解框架要解决什么问题（资源重复加载、内存泄漏、模块间耦合过高等）。
- 从“单例基类 + 对象池 + 事件中心”三个模块开始自己手写一个极简框架。
- 然后将您的上一个游戏项目接入该框架，并对比重构前后的维护成本。
- 后续可以研究更成熟的框架（如 QFramework、ET），但切勿一上来就啃大而全的框架，先从自己动手搭建入手。
