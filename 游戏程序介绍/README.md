# 游戏程序介绍

程序是游戏开发的核心方向之一，负责把设计变成能跑的代码。在我们组里，程序方向以**游戏客户端**为主线（Unity C# / UE5 C++），图形、引擎、服务端是进阶分支，按兴趣深入。

> ⭐ **入门只看 `游戏客户端` 就够了**——学习轮、第一轮考核都在这个范围内。其他三个是分支方向，先打好客户端基础，以后有兴趣再碰。

## 子方向导航

- [游戏客户端](./游戏客户端/README.md) — ⭐ **主线入门**：C# / C++ 语法 + Unity / Unreal 引擎开发
- [游戏引擎](./游戏引擎/README.md) — 进阶：引擎底层原理（Games104）
- [游戏服务端](./游戏服务端/README.md) — 进阶：后端、网络、数据存储

> ℹ️ 渲染 / Shader / 图形学方向（原「图形程序」）已并入美术方向的[技术美术](../游戏美术介绍/技术美术/README.md)，对渲染感兴趣的去看看。

## 学习路线建议

1. **学习轮**：语法（C# 或 C++ 二选一）+ 引擎上手，跟着 `游戏客户端` 的教程走
2. **第一轮**：做你的第一个 demo，用客户端学的东西就够了
3. **进阶**：对底层原理感兴趣 → 游戏引擎；对后端感兴趣 → 游戏服务端；对渲染/图形学感兴趣 → 美术方向的技术美术

> 💡 资料只是参考，B 站和 YouTube 有非常多高质量的教程。更重要是学会**自己搜索优秀教程**的能力——这远比学完我们提供的教程收获更大。
